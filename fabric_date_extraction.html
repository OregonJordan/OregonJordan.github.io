Automated Date Extraction from Unstructured Time Period Labels in a Microsoft Fabric Lakehouse

Enhanced a Direct Lake-connected dimension table (dim_period) by engineering a standardized WE_Date (week-ending date) column from a free-text Time_Description field containing inconsistent period labels (e.g., "Week Ending," "4 Weeks Ending," "Latest 52 Weeks Ending," "Calendar Year Ending"). Used PySpark within a Fabric notebook to apply regular-expression extraction that isolated the embedded MM-DD-YY date regardless of label prefix, then cast the result to a native Delta DATE type using to_date, ensuring proper chronological sorting and filtering for downstream reporting. Applied the transformation via a schema-evolving overwrite (overwriteSchema) that preserved all existing columns and records, then refined the output by renaming the field to align with model naming conventions (WE_Date). The resulting column enabled reliable time-based filtering and relationship-building within the associated Power BI Direct Lake semantic model, eliminating the need for text parsing at the report layer.
