Power Automate Alert Flow

An automated flow that checks Power BI KPI thresholds across client assignments and sends targeted alert emails to the right managers, with results logged for archive and reporting.

Power AutomateDAXPower BI

Flow Description

This flow is designed to do the following:

  • Reads from a master list of clients assigned to each manager and creates the following:
    • Unique list of manager names and email address
    • Unique list of all available assigned clients by Client name, Region and Retailer
  • Runs a query against the Power BI Semantic Model to retrieve YoY performance and volume KPI data for each.
  • Assigns KPI to each manager by merging both lists together based on desk assignments.
  • Builds an output email for each KPI with dynamic Power BI report links for each combination of results.
  • Sends emails.
  • Records outputs to a master record for archive and reporting.
